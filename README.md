## Installation

Clone the repository:

git clone https://github.com/TON-COMPTE/koshibar-shadowsocks.git

cd koshibar-shadowsocks

Build:

docker compose build

Start:

docker compose up -d

Check:

docker compose ps

Logs:

docker compose logs -f

## Stop

docker compose down

## Restart

docker compose restart
